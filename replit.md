
  # DND Game Board

  A real-time DND-style game board for tracking characters and their attributes.

  ## Features
  - Real-time character stat synchronization (Health, Soul Fragments, etc.)
  - Custom character icon uploads
  - Stylized character sheets with editable traits (Memories, Attributes, Echoes, Aspect)
  - Persistent storage using PostgreSQL

  ## Tech Stack
  - Frontend: React, Tailwind CSS, Shadcn/UI, Lucide Icons, Framer Motion
  - Backend: Express, Node.js, WebSocket (ws)
  - Database: PostgreSQL (Drizzle ORM)
  - State Management: TanStack Query (React Query)
